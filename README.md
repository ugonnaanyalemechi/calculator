# Calculator
## Description
A simple arithmetic calculator built using HTML, CSS, and JavaScript.\
Try it here: https://ugonnaanyalemechi.github.io/calculator/

## Features
* **Basic Arithmetic Operations:** Features addition, subtraction, multiplication, and division
* **Decimal Input:** Users can enter decimal numbers
* **Chained Operations:** Users can enter sequential expressions (e.g., `1 + 2 + 3`) without having to press the equal button, as the running total is calculated automatically
* **Keyboard Support:** Users can use corresponding keys to the displayed buttons on the calculator for use; pressing `Backspace` removes a character from the calculator, and pressing `c` resets the calculator state

## Learning Experience Takeaways
* This project was a little more difficult than I initially thought due to having to take the time to understand how I should implement the calculator logic and manage its different states
* What really helped to clarify the logic was by assuming the position of the user and asking myself, "If I pressed this button, what should and should not happen?"
* Gained a better intuitive understanding of how flexbox works
